Creator and core maintainer of **rag-ai-scientist**, a modular framework for evaluating LLM and agent systems over dense scientific corpora. It implements hybrid semantic search, factual-grounding harnesses, and context chunkers used in the CHEP 2026 *Future-Ready Restoration* work on reviving a legacy LHCb analysis.
